# Content rules

CertBuddy helps people prepare honestly. These rules protect learners' certifications and keep the project within AWS's terms. Every lesson, question and contribution must follow them.

## 1. No real exam content, ever

The [AWS Certification Program Agreement](https://aws.amazon.com/certification/certification-agreement/) treats all exam material as AWS confidential information. It must not be disclosed, copied, reproduced or turned into derivative works. Using or sharing "brain dumps" can get a certification revoked ([AWS Training & Certification blog](https://aws.amazon.com/blogs/training-and-certification/protecting-aws-certification-value-through-security-measures)).

- ✅ Write **original** questions from the **public** exam guide's domains and task statements and from public AWS documentation.
- ❌ Never recreate, paraphrase or "remember" a question someone saw in a real exam, including the maintainer's own exam.
- ❌ Never copy questions from dump sites, other paid courses or AWS's official sample or practice question sets.
- ❌ Never describe content as "real exam questions" or "actual exam". Use "**exam-style**".
- If a contribution looks like leaked exam content, it is rejected and removed.

## 2. AWS name and logos

Follow the [AWS Trademark Guidelines](https://aws.amazon.com/trademark-guidelines).

- ✅ Use AWS service names in plain text to describe what is being studied (for example "practice for the AWS Certified Solutions Architect – Associate exam").
- ❌ No AWS logos, the AWS "smile", or AWS Certification badge artwork in the app, the README or social posts.
- ❌ Nothing that suggests AWS sponsors or endorses CertBuddy.
- Every page footer includes: *"Not affiliated with or endorsed by Amazon Web Services. AWS and related marks are trademarks of Amazon.com, Inc. or its affiliates."*

## 3. Documentation and sources

- Explain things in our own words. Link to AWS documentation instead of copying large passages.
- Check every answer explanation against current AWS documentation. Services change, so explanations carry a "last checked" date where it matters.

## 4. Using AWS services

- The site follows the [AWS Acceptable Use Policy](https://aws.amazon.com/aup/): no abuse, no scraping, no spam.
- Narration audio is generated with Amazon Polly. Polly output may be stored and replayed indefinitely ([Amazon Polly FAQ](https://aws.amazon.com/polly/faqs/)).
- Cost guards (budgets, an automatic spend brake, anomaly alerts) are kept on at all times.

## 5. Learners' data and privacy (UK GDPR)

- No adverts, no tracking cookies, no selling or sharing data.
- Store only what's needed: email (optional sign-in) and study progress.
- Learners can delete their account and data at any time.
- A short privacy notice explains all of this in plain words.

## 6. Accuracy and honesty

- No pass guarantees. CertBuddy is a study aid, not an official AWS product.
- Questions with a reported error are hidden until fixed.
